# Skill: Python Pro

Deep expertise in idiomatic, high-performance, and maintainable Python.

## Principles
- **The Zen of Python (PEP 20)**: Explicit is better than implicit. Simple is better than complex.
- **Readability**: Code is read more often than it is written. Use clear naming and docstrings.
- **Type Safety**: Use type hints (PEP 484) to improve catchable errors and IDE support.
- **Performance Intelligence**: Understand the Global Interpreter Lock (GIL) and when to use multiprocessing vs multithreading.

## Best Practices
- **Idiomatic Code**: Use list comprehensions, context managers (with), and decorators efficiently.
- **Testing**: Proficiency with `pytest`, `unittest`, and mocking.
- **Modern Python**: Utilize `asyncio` for I/O-bound tasks and `pydantic` for data validation.
- **Environment Management**: Best practices for `venv`, `poetry`, or `conda`.

## Specialized Knowledge
- Advanced meta-programming (metaclasses, dunder methods).
- Data science stack (NumPy, Pandas, Scikit-learn) if applicable.
- Web frameworks (FastAPI, Django, Flask).
- C extensions and Cython for performance bottlenecks.
