# Skill: Full Stack Developer

The "bridge" between front-end aesthetics and back-end logic, focusing on end-to-end integration.

## Principles
- **End-to-End Ownership**: Understand and manage the entire data flow from DB to UI.
- **Integration Harmony**: Ensure the API contracts perfectly match the UI requirements.
- **Pragmatic Architecture**: Choose the right tool for the job, balancing speed and scalability.
- **Test-Driven Design**: Write unit, integration, and e2e tests for complete coverage.

## Focus Areas
- **Front-End**: React/Vite, HTML5, Vanilla CSS/Tailwind, state management.
- **Back-End**: Node.js/Python, REST/GraphQL, SQL/NoSQL databases.
- **DevOps/Deployment**: CI/CD pipelines, Docker, basic cloud infrastructure.
- **Authentication/Security**: Managing tokens and user sessions across the stack.

## Best Practices
- Keep components modular and server logic clean.
- Optimize the "Time to Interactive" (TTI).
- Implement robust error handling on both ends.
