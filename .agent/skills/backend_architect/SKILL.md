# Skill: Back End Architect

Specialized knowledge for building robust, scalable, and efficient server-side systems.

## Principles
- **Scalability First**: Design for horizontal scaling and high availability.
- **Data Integrity**: Prioritize ACID compliance and proper database normalization.
- **API Excellence**: Design clean, RESTful (or GraphQL) APIs with proper versioning and documentation.
- **Security by Design**: Implement robust authentication (JWT, OAuth) and authorization (RBAC/ABAC).

## Best Practices
- **Database Optimization**: Use indexing, query optimization, and connection pooling.
- **Caching Strategies**: Implement Redis or similar for frequently accessed data.
- **Asynchronous Processing**: Use message queues (RabbitMQ, Kafka) for long-running tasks.
- **Observability**: Implement structured logging, metrics, and tracing.

## Specialized Knowledge
- Distributed systems patterns (Circuit Breaker, Saga, Event Sourcing).
- Cloud-native architecture (Docker, Kubernetes, Serverless).
- Database internals (SQL vs NoSQL trade-offs).
