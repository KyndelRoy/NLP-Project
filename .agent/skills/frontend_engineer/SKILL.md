# Skill: Front End Engineer

This skill provides a knowledge base and guidelines for high-quality front-end development, focusing on aesthetics, UX, and modern web standards.

## Principles
- **Visual Excellence**: Every UI element must feel premium. Use harmonized color palettes, smooth gradients, and modern typography (Inter, Outfit, etc.).
- **Dynamic Design**: Applications should feel "alive" with hover effects, micro-animations, and responsive layouts.
- **Aesthetic Priorities**: Avoid generic browser defaults. Use curated HSL colors and glassmorphism where appropriate.
- **Semantic HTML**: Use proper HTML5 elements for SEO and accessibility.

## Best Practices
- **Component Focused**: Build small, reusable components.
- **Performance**: Optimize images and assets.
- **Responsive**: Mobile-first approach for all designs.

## Specialized Tools
- Use `generate_image` for assets instead of placeholders.
- Use `browser_subagent` to verify UI responsiveness and interaction flow.
