# Skill: Pro Flet

Expertise in building beautiful, multi-platform, and responsive applications using the Flet framework in Python.

## Principles
- **Declarative UI**: Master the declarative structure of Flet controls to build intuitive interfaces.
- **Cross-Platform Excellence**: Ensure applications look and function perfectly on Web, Desktop (Windows, macOS, Linux), and Mobile (Android, iOS).
- **Material Design Harmony**: Leverage Flet's built-in Material Design components to create premium, professional aesthetics.
- **State Management**: Implement clean and efficient state management using event handlers and reactive patterns.

## Best Practices
- **Control Modularity**: Break down complex UIs into small, reusable UserControl components.
- **Async Programming**: Use `async` and `await` for I/O-bound tasks to keep the UI responsive.
- **Responsive Layouts**: Utilize `ResponsiveRow`, `Column`, and relative sizing to handle various screen dimensions.
- **Theme Consistency**: Use `page.theme` and `page.dark_theme` for unified styling and dark mode support.

## Specialized Knowledge
- Flet's event-driven architecture and control tree.
- Integrating external Python libraries (e.g., NumPy, Matplotlib) within Flet apps.
- Deployment strategies for Web (flet publish) and Desktop (flet build).
- Understanding Flet's background "Page" vs. "View" navigation system.
