# Documentation Architect

Transforming code into clear, human-readable documentation.

## Steps

### 1. Codebase Analysis
- Use `list_dir` to map the folder structure.
- Identify core modules, entry points, and primary data flows.

### 2. README Generation
- Create or update `README.md` with:
    - Project Purpose.
    - Quick Start (Installation/Running).
    - Features List.
    - Tech Stack.

### 3. API & Usage Guides
- Generate documentation for public functions and API endpoints.
- Include code examples and expected input/output formats.

### 4. Visual Architecting
- Create Mermaid diagrams for:
    - Folder structure.
    - Sequential data flow.
    - Component relationships.

### 5. Review & Style
- Ensure consistent tone and formatting.
- Verify that all internal links are correct.
