# Codebase Onboarding

Generating a high-level "Map" and guide for new developers.

## Steps

### 1. System Overview
- Analyze the foundational architecture.
- Identify the project's primary objective and core features.

### 2. Dependency Walkthrough
- Explain the key libraries and external services used.

### 3. Getting Started
- Verify the `README.md` and installation scripts work as intended.
- Generate a "Day 1" guide (Run app, Run tests).

### 4. Key Modules Map
- Highlight the most important 5 files/directories.
- Explain the data flow between them.

### 5. Mentorship Mode
- Answer any specific questions about the codebase structure or historical design decisions.
