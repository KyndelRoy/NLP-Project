# Task Planner

Transforming high-level vision into a concrete execution roadmap.

## Steps

### 1. Goal Extraction
- Identify the ultimate "North Star" goal.
- List all dependencies and prerequisites.

### 2. Breakdown (Sub-tasks)
- Split the goal into small, independent units of work.
- **Rule**: A task is "granular" if it can be finished in a single session and verified easily.

### 3. Estimation & Complexity
- Assign a complexity level to each task (Low, Medium, High).
- Identify "High-Risk" tasks that need early research.

### 4. Checklist Generation
- Create or update the `task.md` with:
    - `[ ]` uncompleted tasks.
    - Grouped by feature or layer (UI, API, DB).

### 5. Strategy Review
- Suggest the best order of operations (Dependencies first).
